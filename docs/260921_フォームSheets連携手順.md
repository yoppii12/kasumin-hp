# フォーム → Google Sheets 連携 導入手順（KASUMIN版）

kasumin.biz のお問い合わせフォーム（/contact）の送信内容をスプレッドシートに記録し、
担当者へ通知メール＋訪問者へ自動返信を送るための手順。
laplust-hp `docs/260903_フォームSheets連携手順.md` を雛形に作成（詳細な運用メモ・
営業メール判定の解説はそちらを参照。スクリプトの仕組みは同一）。

## 全体像

```
フォーム送信 → GAS WebアプリURL → スプレッドシートに1行追記 ＋ 通知メール ＋ 自動返信
```

- 記録先スプレッドシート: https://docs.google.com/spreadsheets/d/1_Mqhey424rlO-74c2bTahlE5UxEUI1h8_NmmpVKInso/edit
  （h.kasumi@kasumin.biz 作成・GAS実行アカウントも同アカウント）
- シートのタブ「お問い合わせ」は初回送信時に自動作成される（手動作成不要）
- 通知先: info@kasumin.biz / 自動返信の差出人: (自動返信)合同会社KASUMIN <info@kasumin.biz>
- honeypot（隠し入力欄）によるスパム除外と、営業メール判定（件名に【営業の可能性】）付き

## 手順（Google側の作業・約10分）

1. 上記スプレッドシートを開き、「拡張機能」→「Apps Script」
2. `コード.gs` の中身を全部消し、リポジトリの `scripts/gas/form-receiver.gs` を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 歯車 →「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（サイト訪問者の送信を受けるため）
4. 初回はアクセス承認（「確認されていません」→「詳細」→「移動」で許可）
5. 表示される **WebアプリのURL**（`https://script.google.com/macros/s/…/exec`）を開発側へ共有
   → `site/lib/submitForm.ts` の `GAS_ENDPOINT` に設定して送信テストを実施

## 自動返信の前提（エイリアス）

実行アカウントのGmailで **info@kasumin.biz が「他のメールアドレスから送信」に登録**されて
いること。未登録でも受付・記録・通知は成立し、自動返信のみ失敗する（通知メール内に
「自動返信: 失敗」と表示される）。登録状況はエディタで `logAliases` を実行して確認できる。

## 運用メモ

- スクリプト修正後の反映は「デプロイ」→「デプロイを管理」→ 鉛筆 → 新バージョン → デプロイ
  （**「新しいデプロイ」で作り直すとURLが変わる**ので注意）
- シート右側に「対応状況」等の列を自由に追加してよい（行追記なので壊れない）
- 問い合わせ内容は個人情報のため、シートの共有は必要最小限に
