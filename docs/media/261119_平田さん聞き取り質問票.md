# 平田さん 聞き取り質問票（2026-11-19）

オウンドメディア「えんまーるの えんだより」の記事のうち、**平田さんにしか書けないところ**だけを集めた質問票です。
制度・数字の確認（専門家や市への確認）は LAplust 側で進めるので、ここには入れていません。

## 答え方

- 箇条書き・話し言葉・音声メモ、どれでも大丈夫です。文章には LAplust（Claude）が整えます
- **実際に経験したこと・本当に思っていることだけ**を書いてください。思い出せない・経験がない質問は「なし」で大丈夫です（その段落は記事から外します）
- 人が出てくるエピソードは、本人の許可が取れるものだけにしてください。記事では、名前・園名・地域が分からない形にします
- 園長時代の話は、園が特定できない書き方にします（「東京都世田谷区の保育園」までにします）
- 目安の時間: A は30分ほど（通話の録音でも可）、B〜E は合わせて30〜40分ほど
- 優先度: ★ = 公開に必要（記事に空欄がある） ／ ☆ = あると記事が良くなる
