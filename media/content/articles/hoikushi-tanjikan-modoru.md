「フルタイムは難しいけれど、午前だけなら」「週2日なら」。短い時間からでも、保育の現場に戻る方法はあります。始める前に知っておきたいことをまとめました。

短い時間で働くときに考えることは、大きく分けて「いつ働くか」「いくらまで働くか（扶養・税・社会保険）」「子どもをどこに預けるか」「どんな役割で入るか」の4つです。この記事では、その順に全体を見渡し、詳しい内容はそれぞれの記事へつないでいます。

## 1. 先に「働ける時間」を決める

| 決めること | 例 |
|---|---|
| 曜日 | 火・木の週2日 |
| 時間帯 | 9時〜13時（午前のみ） |
| 年収の目安 | 扶養の範囲に収めたいか |
| 子どもの預け先 | 保育所・幼稚園・家族など |

条件を先に決めておくと、園に相談するときに話が早く進みます。

4つは別々に決めるものではなく、互いにつながっています。たとえば「子どもを保育所に預けたい」なら、預けるための就労時間の基準に届く日数が必要です。「扶養の範囲に収めたい」なら、働く日数と時間に上限が出てきます。曜日と時間帯は、家族の予定やお迎えの時間から逆算して、「この時間なら無理なく続けられる」という幅で考えておくと安心です。

年収の目安は、時給×1日の時間×週の日数×52週でおおよそ見積もれます。仮に時給1,100円で計算すると、次のようになります（祝日や長期休みは考えていない概算です）。

| 働き方 | 年収の目安 |
|---|---|
| 1日4時間×週2日 | 約46万円 |
| 1日4時間×週4日 | 約92万円 |
| 1日4時間×週5日 | 約114万円 |
| 1日5時間×週5日 | 約143万円 |

実際の時給は園や地域によって違います。求人の時給の見方は「[長崎で保育士のパートを探すときの時給の見方](/articles/nagasaki-hoikushi-part-jikyu)」でまとめています。

## 2. 扶養内で働くなら、3つの基準を分けて考える

| 基準 | 2026年の目安（給与収入のみの場合） |
|---|---|
| 所得税がかからない | 178万円以下（2026年・2027年分の特例） |
| 住民税がかからない | 自治体で違う（長崎市は2026年度、単身で約106.5万円以下） |
| 社会保険の扶養に入れる | 130万円未満（労働契約の内容で判断） |

```slide
title: 扶養内で働くときの3つの基準
- 所得税：178万円以下ならかからない（2026年・2027年分の特例）
- 住民税：自治体で違う（長崎市は2026年度、単身で約106.5万円以下）
- 社会保険の扶養：130万円未満（労働契約の内容で判断）
summary: 「扶養内」は1つの数字ではなく、基準ごとに分けて考えます
```

「扶養内」という言葉は1つに聞こえますが、実際には基準ごとに数字も、超えたときに起きることも違います。

所得税の178万円は、所得税だけの基準で、2026年分と2027年分の特例です。2026年は、11月までの毎月の給与から引かれる所得税（源泉徴収）はこれまでどおりで、12月の年末調整で1年分を計算し直して精算します。そのため、年収が178万円以下でも、毎月の給与からは所得税が引かれていることがあります。

住民税は、前の年の1年間の所得をもとに、翌年の6月から納める仕組みです。社会保険の扶養は、2026年4月から、労働契約で決まった賃金（諸手当・賞与も含みます）から見込む年収で判断されるようになりました。上の表で年収143万円になる働き方は、社会保険の扶養の130万円を超えます。

詳しくは「[保育士が扶養内で働くときの最新の計算](/articles/hoikushi-fuyounai-2026)」でまとめています。

## 3. 社会保険に入るかどうか

勤務先で社会保険（厚生年金・健康保険）に入るのは、週の所定労働時間が20時間以上で、勤務先の法人の規模などの条件を満たす場合です。月8.8万円の賃金の条件は2026年10月になくなりました。午前のみ・週2日など週20時間未満の働き方なら、原則として加入の対象にはなりません。

加入の条件は、次の4つをすべて満たすことです。

- 週の所定労働時間が20時間以上
- 勤め先の法人全体で、厚生年金に入っている人が51人以上（2027年10月から36人以上）
- 2か月を超えて働く見込みがある
- 学生でない

「所定労働時間」は、雇用契約書や就業規則で決まっている、ふだんの週の勤務時間のことです。残業は原則として含みませんが、いつも残業がある場合などは含めて考えることがあります。

たとえば1日4時間・週5日は週20時間なので、法人の規模などの条件を満たせば加入の対象になります。1日4時間・週4日（週16時間）なら、原則として対象になりません。勤務先の社会保険に入ると、自分で保険料を払うことになり、配偶者の社会保険の扶養からは外れます。週何時間で契約するかは、扶養との関係もふまえて、契約の前に園と話しておきましょう。

## 4. 子どもの預け先を確かめる

保育所に子どもを預けるには、自治体が決める就労時間の基準を満たす必要があります。長崎市は月64時間以上です。詳しくは「[子育て中に保育士に戻るとき](/articles/hoikushi-kosodate-fukki)」でまとめています。

```slide
title: 子どもを保育所に預けるときの基準（長崎市）
- 保育短時間：月64時間以上120時間未満の就労
- 保育標準時間：月120時間以上の就労
- 1日4時間×週2日（月約34時間）では届かない可能性が高い
- 仕事を探している間も、求職活動として利用できる場合がある
summary: 働く日数を決める前に、預けるための基準を確かめます
```

国のルールでは、働くことを理由に保育所を利用する場合、市町村が月48〜64時間の範囲で下限を決めます。長崎市では、月64時間以上120時間未満の就労が「保育短時間」、月120時間以上が「保育標準時間」の区分です。

月の就労時間は「週の時間×約4.3週」で見積もれます。1日4時間・週2日なら月約34時間で、長崎市の基準には届かない可能性が高くなります。1日4時間・週4日なら月約69時間で、基準に届きます。「短い時間で働きたい」と「保育所に預けたい」は、日数の考え方がぶつかることがあるので、先に確かめておくと安心です。

仕事を探している段階でも、求職活動を理由に保育所を利用できる場合があります（長崎市は入所が決まってから90日目を迎える日の月末まで）。保育士として働く人の子どもが保育所に入りやすくなるよう工夫することを、国は自治体に求めていますが、義務ではなく、扱いは自治体ごとに違います。

## 5. 「保育補助」から始める選択肢もある

いきなり担任と同じ役割は不安、という方は、保育補助として入る方法もあります。詳しくは「[資格はあるけれど保育補助で戻りたい](/articles/hoikushi-hoikuhojo-shikakuari)」へ。

保育補助として働くときに大切なのは、自分が「保育士登録」をしているかどうかです。保育士登録をしている方は、職名が「保育補助」でも法律上は保育士です。資格を取っただけで登録をしていない方は、「保育士」と名乗ることはできませんが、補助として働くことはできます。

補助から始める場合は、仕事の内容や時給、慣れてきたら保育士としての勤務に切り替えられるかを、契約の前に確かめておくと安心です。国には、保育士として働いていない有資格者が補助として段階的に戻るための事業（保育補助者雇上強化事業）もありますが、実施するのは市区町村で、長崎市で実施しているかは確認中です。

## 6. 短い時間の募集を探す

短い時間の募集を探す方法はいくつかあります。働きたい園が決まっているなら、園に直接問い合わせる方法があります。長崎県の保育士・保育所支援センター「保いっぷ」では、就職の相談や園の見学の同行もしています。使い方は「[保いっぷの使い方](/articles/hoippu-guide)」でまとめています。

まずは1日だけ働いてみたい、という方は、単発・スポットの働き方もあります。始める前に知っておきたいことは「[保育士が単発・スポットで働く前に知っておきたいこと](/articles/hoikushi-spot-hajimekata)」へ。

長崎県の「保育士就職準備金」（20万円以内、2年間続けて働くと返還免除）は、保育士として週20時間以上働くことが条件の1つです。週20時間未満の働き方では対象になりません。

午前だけ働く場合の一日の流れは「[午前だけ働く保育士の一日](/articles/hoikushi-gozen-nomi-ichinichi)」でまとめています。

えんまーるは、長崎を中心に、午前のみ・単発・週1などの短い時間の募集を見て応募できる情報提供プラットフォームです。雇用契約は園と保育士が直接結び、給与は園から支払われます。保育士がえんまーるに払う料金はありません。
