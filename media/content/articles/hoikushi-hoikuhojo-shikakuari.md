「ブランクが長いので、まずは補助から始めたい」。そう考える方は少なくありません。保育士資格を持つ方が保育補助として働くときに知っておきたいことをまとめました。

補助から始めるかどうかは、短い時間で戻るときの選択肢の1つです。働く時間の決め方や扶養・子どもの預け先まで含めた全体の流れは、「[午前だけ・週2・扶養内で保育士に戻る方法](/articles/hoikushi-tanjikan-modoru)」でまとめています。

## 保育士登録をしているかどうかで違う

| | 保育士登録をしている | 資格はあるが登録していない |
|---|---|---|
| 「保育士」と名乗れるか | 名乗れる | 名乗れない（名称独占） |
| 補助として働けるか | 働ける | 働ける |
| 法律上の扱い | 職名が補助でも保育士 | 保育士ではない |

```slide
title: 保育士登録の有無で変わること
- 登録している方は、職名が「保育補助」でも法律上は保育士
- 登録していない方は「保育士」と名乗れない（名称独占）
- どちらの方も、補助として働くことはできる
- 登録は都道府県の保育士登録簿に。登録すると保育士登録証が交付される
summary: まずは自分が「登録」まで済んでいるかを確かめます
```

保育士になるには、保育士登録簿への登録が必要です（登録すると保育士登録証が交付されます）。保育士でない人が保育士と名乗ることは法律で禁止されています。

児童福祉法では、保育士を「保育士登録を受け、保育士の名称を用いて、児童の保育と保護者への保育に関する指導を行う人」と定めています。養成校を卒業したり、保育士試験に合格したりしただけでは「保育士となる資格がある」状態で、都道府県の保育士登録簿に登録を受けて、はじめて保育士になります。保育士でない人が保育士やこれに紛らわしい名称を使った場合は、30万円以下の罰金の対象です。

登録しているかどうか分からない場合や、保育士登録証をなくしてしまった場合は、登録事務処理センターに問い合わせてみましょう。保育士には、仕事で知った秘密を漏らしてはいけない義務があり、保育士でなくなった後も続きます。

## 補助として入っても、保育士として数えられる？

配置基準（子どもの年齢ごとに必要な保育士の人数）に数えられるのは保育士です。保育士登録をしている方は、職名が「補助」でも法律上は保育士なので、配置基準に数えることはできます。ただし、実際に数えるかどうかは、園が勤務の形や配置をどう決めるかによります。

| 子どもの年齢 | 保育士1人あたりの子どもの数（おおむね） |
|---|---|
| 0歳 | 3人 |
| 1・2歳 | 6人 |
| 3歳 | 15人 |
| 4歳以上 | 25人 |

保育所の保育士の数は、国の省令で上の表のように決まっていて、どんなに小さな保育所でも2人を下回ってはいけません（3歳以上の基準には経過措置があります）。たとえば1歳児が12人いるクラスなら、保育士が2人以上必要です。

配置基準に数えられる立場で入ると、その時間はクラスの保育を担う1人として扱われます。数えられない立場で入る場合は、担任の保育士を支える役割が中心になります。どちらの立場で入るのかによって、任される仕事や責任の重さが変わるので、働き始める前に園に確かめておくと安心です。配置基準について、くわしくは「[スポット勤務の保育士は配置基準に入る？](/articles/hoikushi-spot-haichi-kijun)」でもまとめています。

## 国の「保育補助者雇上強化事業」

国（こども家庭庁）は、園が保育補助者を雇う費用を補助する事業を行っています（市区町村が実施）。対象は次の2つです。

- 保育士資格を持たない保育補助者
- 保育士資格を持つ保育補助者（保育士として働いていない有資格者が、補助として段階的に復帰するため。補助の対象は1年まで）

<!-- 【要確認】長崎市・長崎県内で実施しているか、対象の条件（配置基準の外であることが必要か等）を自治体に確認して追記する -->

この事業は2016年度（平成28年度）に始まりました。目的は、保育補助者を雇うことで保育士の業務の負担を軽くし、保育士の離職を防ぐことと、保育士として働いていない有資格者（いわゆる潜在保育士）の再就職を支えることです。資格を持たない保育補助者については、園が保育士資格の取得を促すことになっています。

資格を持つ方の枠は、一定の期間を補助として働き、保育士として戻るときの足がかりにするためのものです。補助の対象になる期間は1年が限度です。この事業を使うかどうかは、実施する市区町村と園によります。働き始める前に、園がこの事業を使っているか、1年たった後の働き方をどう考えているかを聞いておくと、見通しが立てやすくなります。

## 補助から始めるときに確かめたいこと

| 確かめること | 例 |
|---|---|
| 職名と仕事の内容 | 補助としてどこまで任されるか |
| 時給 | 保育士として雇われる場合と違うか |
| ステップアップ | 慣れたら保育士としての勤務に切り替えられるか |

職名・仕事の内容・時給は、働き始めるときに受け取る労働条件通知書や雇用契約書で確かめられます。口頭で聞いた内容と書面が違うときは、契約の前に確認しましょう。

長崎県の「保育士就職準備金」（20万円以内、2年間続けて働くと返還免除）は、県内の保育所等に、新たに保育士として週20時間以上勤めることが条件の1つです。補助という職名で働く場合や、週20時間未満の場合に対象になるかは、申請の前に長崎県社会福祉協議会に確かめてください。制度の内容は「[長崎県の保育士就職準備金は20万円](/articles/nagasaki-shushoku-junbikin)」でまとめています。

- 就職の相談や園の見学の同行：「[保いっぷの使い方](/articles/hoippu-guide)」

どの働き方から始めても、慣れてきたら少しずつ役割を広げていく道があります。迷ったときは、園や相談窓口に今の気持ちを率直に伝えてみてください。
