長崎県には、現場を離れていた保育士がもう一度保育所等で働くときに使える「保育士就職準備金」があります。働き始めるときは、仕事で着る服や靴をそろえたり、通勤の手段を用意したりと、思った以上にお金がかかるものです。この制度は、そうした準備にかかる費用を20万円まで無利子で借りられ、県内の保育所等で2年間続けて働けば返さなくてよくなる仕組みです。

この記事は、令和8年度（2026年度）の募集要項にもとづいてまとめています。募集は年度ごとで、内容が変わることがあります。申請する前に、必ず最新の募集要項を確認してください。

## 制度のあらまし

| 項目 | 内容 |
|---|---|
| 貸付額 | 20万円以内（1人1回、無利子） |
| 返還免除 | 県内の保育所等で2年間続けて働くと全額免除 |
| 申請の期限 | 就職してから3か月以内 |
| 募集期間 | 2026年4月1日〜2027年2月28日（必着） |
| 募集人数 | 20名程度 |
| 実施 | 長崎県社会福祉協議会（福祉人材センター） |

「貸付」なので、いったんお金を借りる形です。ただし、条件どおりに2年間続けて働けば返す必要はなくなります。利子はかかりませんが、返すことになった場合に最終の返還期限を過ぎると、年3%の延滞利子がかかります。

募集人数は20名程度と決まっています。就職が決まったら、早めに準備を始めましょう。

## 何に使えるか

保育士として働き始めるために必要な費用に使えます。

- 仕事で使う衣服・靴・鞄
- 通勤用の自転車など
- 敷金・礼金・引っ越しの費用
- 講習会・研修会の参加費
- そのほか就職に必要な費用

たとえば、保育の仕事で着る動きやすい服や靴をそろえる、園までの通勤に使う自転車を用意する、といった使い方が考えられます。県外から長崎に戻って働く方や、勤務先の近くに引っ越す方は、敷金・礼金や引っ越しの費用にも使えます。ブランクがあって不安な方は、復帰の前に研修や講習会に参加する費用に充てることもできます。

## 対象になる人（すべて満たす）

1. 保育士として登録してから1年以上たっている
2. 認可保育所等を離職してから1年以上たっている、または認可保育所等で働いたことがない
3. 県内の保育所等に、新たに保育士として週20時間以上勤める
4. 保育士修学資金の「就職準備金」を受けていない

4つの条件は、どれか1つではなく、**すべて**満たす必要があります。

1の「登録してから1年」は、資格を取った日ではなく、保育士登録をした日から数えます。登録した日は保育士登録証に書かれています。

2の「認可保育所等」には、認可保育所・幼保連携型認定こども園・小規模保育事業・家庭的保育事業・事業所内保育事業に加えて、幼稚園も含まれます。幼稚園で働いていた方は、その幼稚園を辞めてからの期間で数えます。

3の「週20時間以上」は、パートでも条件を満たせば対象になります。雇用形態ではなく、勤務時間で決まります。たとえば1日4時間・週5日、1日5時間・週4日といった働き方です。

### 勤め先が対象になるか

「保育所等」には、次のような施設が含まれます。

| 施設の種類 | 例 |
|---|---|
| 保育所・認定こども園 | 認可保育所、幼保連携型認定こども園など |
| 地域型保育など | 家庭的保育事業など |
| その他の保育 | 企業主導型保育事業、病児保育、一時預かり、離島等の特例保育、自治体単独の認可外施設など |
| 幼稚園 | 預かり保育を週5日以上常に実施しているところに限る |

勤め先が対象になるか分からないときは、申請の前に問い合わせてください。

## 申請の流れ

![申請から返還免除までの流れ](/images/diagrams/nagasaki-shushoku-junbikin-flow.svg)

申請できるのは、**就職した後**です。就職が決まる前には申請できません。雇用契約書の写しが必要になるので、勤め先と契約を結んでから準備を始めます。期限は勤務を始めてから3か月以内なので、働き始めて仕事に慣れるまでの忙しい時期と重なります。就職が決まった時点で書類の準備を進めておくと安心です。

送金される額は、借用書に貼る収入印紙の代金を引いた額になります（10万円以下は200円、10万円を超える場合は400円）。

### 主な提出書類

- 申請書、個人情報の取扱いの同意書、借用書
- 通帳の写し、雇用契約書の写し、保育士証の写し
- 住民票（申請者と連帯保証人。世帯全員・続柄あり・マイナンバーなし）
- セルフチェックシート

連帯保証人は、一定の収入がある方が1名必要です。早めにお願いしておきましょう。様式は長崎県社会福祉協議会のページからダウンロードできます。

## 返還が免除される条件と、返還が必要になる場合

県内の保育所等で2年間続けて働くと、借りたお金は全額返さなくてよくなります。働いている間は返還が猶予され、勤務の状況を報告します。

| 場合 | 扱い |
|---|---|
| 2年間続けて働いた | 全額免除 |
| 災害・病気・けがなどで、やむを得ず働けなかった期間がある | 続けて働いているものとみなされる（ただし2年の期間には数えない） |
| 保育所等で働く意思がなくなった | 返還が必要 |

たとえば、病気で数か月休んだ場合も、その期間は「続けて働いている」と扱われます。ただし休んだ期間は2年に数えないので、免除になるのはその分あとになります。

| 用途 | 窓口 |

| 書類の提出先 | 長崎県保育士・保育所支援センター（〒850-8570 長崎市尾上町3-1 長崎県こども未来課内） |
| 制度の問い合わせ | 長崎県社会福祉協議会 ふくしのお仕事ステーション 貸付担当（095-846-8656） |

提出先の長崎県保育士・保育所支援センターは「保いっぷ」の愛称で、就職の相談や園の見学の同行もしています。使い方は「[保いっぷの使い方](/articles/hoippu-guide)」でまとめています。

## 学生向けの「就職準備金」とは別の制度です

保育士養成校の学生向けにも「就職準備金」（保育士修学資金の一部）がありますが、別の制度です。学生向けは卒業するときに送金され、返還免除には県内で5年間働く必要があります（過疎地域等は3年）。この記事の就職準備金は、2年間で免除になります。

学生のときに修学資金の「就職準備金」を受けた方は、この記事の就職準備金は使えません。
