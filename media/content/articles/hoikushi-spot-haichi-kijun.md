単発で保育の現場に入るとき、「自分はクラスの人数に数えられるのかな」と気になる方もいるかもしれません。国の通知と配置基準をもとに整理します。

先に結論を書くと、こども家庭庁は、スポットワークで採用された保育士を配置基準の人数に充てることは「望ましくない」としています。ただし禁止ではなく、急な欠勤のときなどに活用することは一概に妨げられないとされています。単発で働くときの全体の注意点は「[保育士が単発・スポットで働く前に知っておきたいこと](/articles/hoikushi-spot-hajimekata)」でまとめています。

## 保育所の配置基準

| 子どもの年齢 | 保育士1人あたりの子どもの数（おおむね） |
|---|---|
| 0歳 | 3人 |
| 1・2歳 | 6人 |
| 3歳 | 15人（2028年3月末までは20人でも可） |
| 4・5歳 | 25人（当分の間は30人でも可） |

3歳児と4・5歳児の基準は2024年4月に改善されました（経過措置あり）。1歳児の「5人に1人」は配置基準ではなく、国の加算（2025年度から）による改善です。

配置基準は、「児童福祉施設の設備及び運営に関する基準」という国の省令で決まっています。こども家庭庁の通知では「最低基準」と呼ばれていて、これを下回ってはいけない人数です。また、どんなに小さな保育所でも、保育士は1か所につき2人を下回ってはいけないとされています。

たとえば、0歳児が6人、1歳児が12人いるクラスなら、単純に計算すると0歳児に2人、1歳児に2人で、保育士が4人以上必要になります。

## こども家庭庁の通知（2025年2月14日）

```slide
- 1〜2日の短期の雇用を長く繰り返すことは「望ましくない」
- 法的な禁止ではなく、国から自治体への助言
summary: 禁止ではないものの、定数の一部にすることは望ましくないとされています
```

通知では、スポットワーク（短時間かつ単発の就労を内容とする雇用契約の下で働くこと）で採用された保育士について、次のように書かれています。

- 最低基準上の保育士の人数の一部に充てることは「望ましくありません」
- 病気などで当日に急な欠勤が出たときに活用することなどは「一概に妨げられるものではない」
- 1〜2日程度の短期の雇用を長期かつ継続的に繰り返すことは「望ましくない」

この通知は法的な禁止ではなく、国から自治体への助言（技術的助言）です。

通知の対象は保育所だけではありません。小規模保育などの基準（家庭的保育事業等の設備及び運営に関する基準）で決まっている保育士の人数も、同じ扱いです。通知は、都道府県から市区町村へ、市区町村から地域の保育所等へ伝えるよう求めています。

### なぜ「望ましくない」とされているか

通知は理由として2つを挙げています。1つは、配置基準の保育士は、子どもを長い時間保育できる常勤の保育士が原則で、望ましいとされてきたこと（2021年3月19日の短時間勤務の保育士についての通知）。もう1つは、子どもとの安定的・継続的な関わりが大切だということです。

## 単発で入ったときに任されることが多い仕事

<!-- 【要確認】平田さんの園長経験から、単発・短時間の保育士さんにお願いしていた仕事を書く（例：休憩の交代、午睡の見守りの補助、行事の準備など。実際に頼んでいたものだけ） -->

| 確かめること | 例 |
|---|---|
| 入るクラス・年齢 | 0歳児クラス、幼児クラスなど |
| 役割 | 担任の補助、休憩の交代、行事の準備 |
| 時間帯 | 午前のみ、午睡の時間、夕方の延長保育など |
| 引き継ぎ | アレルギー、配慮が必要な子どもの情報をどう伝えてもらえるか |

配置基準の人数とは別に入る場合、単発の保育士は担任の先生を支える役割になることが多くなります。ただ、補助の立場でも、子どもの命と安全にかかわることは変わりません。特に、食物アレルギーのある子ども、体調に気をつけたい子ども、午睡中の見守りの方法などは、その日の保育に入る前に聞いておきたいことです。

応募する前に募集の内容で確かめ、分からないところは働く前に園に聞いておくと、当日に慌てずにすみます。また、2026年12月25日から日本版DBS（こども性暴力防止法）が始まると、急な欠員などで性犯罪歴の確認が終わる前に働く場合は、確認が終わるまで原則として子どもと一対一にしないなどの対応がとられます（こども家庭庁のQ&A）。

## 同じ園で何度も単発で働くときは

通知は、園が保育士の人数をどう数えるかについての考え方で、保育士がスポットワークで働くこと自体を禁じるものではありません。急な欠勤の穴を埋める、行事の日に手を貸すといった形で、単発の保育士が園の助けになる場面はあります。

一方で、通知は「1〜2日程度の短期の雇用を長期かつ継続的に繰り返すこと」を望ましくないとしています。同じ園に単発で何度も通うようになり、「この園で続けたい」と感じたら、同じ園で週に数日のパートとして働けないか、園に相談してみるのもひとつの方法です。続けて関わることができれば、子どもの顔と名前、園のやり方も覚えやすくなります。

短い時間で続ける働き方は「[午前だけ・週2・扶養内で保育士に戻る方法](/articles/hoikushi-tanjikan-modoru)」でまとめています。
