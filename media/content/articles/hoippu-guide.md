「保いっぷ」は、長崎県保育士・保育所支援センターの愛称です。保育士として働きたい方の相談から、園の見学、就職した後の相談まで、無料で使えます。

長崎県で使える支援は、保いっぷのほかに就職準備金や相談会などがあります。全体を先に知りたい方は「[長崎県で保育士に戻るときに使える支援の全体像](/articles/nagasaki-hoikushi-fukushoku-shien)」から読むと、どの順で使えばよいかが分かります。

## 保いっぷの基本情報

| 項目 | 内容 |
|---|---|
| 正式名称 | 長崎県保育士・保育所支援センター |
| 場所 | 〒850-8570 長崎市尾上町3-1 長崎県庁1階（こども未来課内） |
| 電話 | 095-895-2687 |
| FAX | 095-895-2554 |
| メール | hoippu-nagasaki@pref.nagasaki.lg.jp |
| 受付時間 | 月〜金 9:00〜17:00（祝日・年末年始を除く） |
| 費用 | すべて無料 |
| 公式サイト | https://www.nagasaki-shiencenter.jp/ |

保いっぷは、長崎県が設けている窓口で、県庁1階のこども未来課の中にあります。窓口に行けない方も、電話・メール・LINE・オンラインで相談できます。

公式サイトの「求人情報をみる」からは、県内の保育所等の求人情報を見ることができます。まずはサイトでどんな求人があるかを眺めてみて、気になったら相談する、という使い方もできます。

## 保いっぷでできること

- 就職の相談（対面・電話・オンライン）
- 保育所等の求人情報の提供
- 園の見学（スタッフの同行も可）と面接の日程の調整
- 職場体験会
- 就職した後の相談
- 修学資金・就職準備金など、お金の制度の案内

相談できるのは、保育士の資格を持つ方と、子育て支援員の研修を修了した方です。ブランクが長い方や、まだ戻るかどうか決めていない方の相談も受け付けています。

いま保育の仕事をしている方向けに、悩みを聞く「保育ほっと相談」や研修の情報の提供もあります。働き始めた後に困ったことがあっても、同じ窓口に相談を続けられます。

お金の制度のうち、復職する保育士さんが使えるのは「保育士就職準備金」です。申請書類の提出先も保いっぷなので、あわせて相談できます。条件は「[長崎県の保育士就職準備金](/articles/nagasaki-shushoku-junbikin)」でまとめています。

## 求職登録の方法

1. 公式サイトの「人材登録」から「求職登録」を開く
2. 希望の勤務地・勤務時間・働き方などを入力する
3. センターから連絡が来て、相談に進む

サイトでの登録が難しい場合は、紙の求職票をメール・FAX・郵送で送ることもできます。

登録の前に「話を聞いてから決めたい」という場合は、問い合わせフォーム・電話・LINEで先に相談できます。来所・電話・メール・LINEでの相談から始めてもよいと、保いっぷ自身が案内しています。

## 登録してから働き始めるまでの流れ

```slide
title: 保いっぷに登録してから働き始めるまで
- 公式サイト・LINE・紙の求職票で登録する
- スタッフから電話。希望を聞いて施設の情報を案内
- 気になる園を見学（スタッフの同行も可）
- 面接の日程はセンターが調整。就職後も相談できる
summary: 登録から就職後まで、同じ窓口に相談できます
```

登録した後は、次のように進みます。

1. センターのスタッフから電話があり、働きたい地域・時間・働き方などの希望を聞かれます。希望に合う施設の情報を案内してもらえます。来所できる方は対面で、希望すればオンラインでも相談できます
2. 希望に合う新しい求人が出たときは、メールで知らせてもらえます
3. 気になる施設があれば、センターに連絡します。希望すれば、スタッフと一緒に見学できます
4. 応募するときは、面接の日程の調整もセンターが行います
5. 就職が決まったらセンターに連絡します。求職票はそこで取り下げになります

就職した後も、続けて相談にのってもらえます。見学や面接に一人で行くのが不安な方は、スタッフの同行をお願いできることを覚えておくと心強いです。

## LINEで相談の予約ができる

保いっぷには公式LINEがあり（2026年8月開設）、メニューから求職登録・相談予約ができます。電話をかけるのが気が重い方は、LINEから始めると気軽です。

LINEでは、新しい求人の情報や、イベント・相談会の情報も届きます。保いっぷは「情報だけ知りたい」という方の登録も歓迎しているので、すぐに働くつもりがなくても、友だち追加をして様子を見ることができます。

ハローワーク長崎での巡回相談の予約も、LINEのメニューの「相談予約」からできます。2026年8月からはInstagramも始めています。

## 見学・職場体験会の申し込み

「どんな園なのか、働く前に見てみたい」という方のために、見学・職場体験会があります。

| 項目 | 内容 |
|---|---|
| 期間 | 2026年7月1日〜2027年2月26日（年末年始・お盆・祝日を除く） |
| 時間 | 1回90分（10:00〜11:30／14:00〜15:30） |
| 申込 | 希望の施設を3つまで選んで申し込む |
| 費用 | 無料（保険はセンターが加入） |
| その後 | 体験後20日以内にアンケートを提出 |

```slide
title: 見学・職場体験会の申し込みの流れ
- 受け入れ施設の一覧から、希望の園を3つ選ぶ
- 申込フォームから保いっぷに申し込む
- センターが日時・場所を調整し、メールで連絡
- 当日は10分前までに園へ。体験後20日以内にアンケート
summary: 費用は無料。希望すればスタッフも同行します
```

申し込みの流れは次のとおりです。

1. 県のホームページか保いっぷのサイトに載っている受け入れ施設の一覧から、希望の施設を3つ決める
2. 申込フォームから保いっぷに申し込む
3. センターが希望と施設の受け入れ体制を調整して、日時と場所を決める（希望すればスタッフも同行）
4. メールで受け入れが決まったことの連絡が来る
5. 当日は10分くらい前までに施設に着くようにする

90分のうち、約30分が施設の説明、約60分が施設内の見学と体験活動です。いまの保育の流れや、子どもとの関わり方に触れることができます。

## ハローワークと一緒に使う

ハローワークの窓口で「支援センターの支援も希望する」と伝え、連携の同意書に署名すると、両方の支援を受けられます。ハローワーク長崎では、毎月第3火曜に保いっぷの巡回相談もあります（日程は「[長崎の保育士向け相談会・カフェの日程](/articles/nagasaki-hoikushi-event-calendar)」）。

巡回相談の時間は10:00〜12:00で、予約が優先です。予約は保いっぷに電話するか、LINEのメニューの「相談予約」からできます。県庁まで行くのが難しい方も、ハローワークに行く日に合わせて相談できます。

雇用保険の失業給付を受けている方は、保いっぷを通じた園の見学や面接への応募が、求職活動の実績の対象になるとされています。詳しくはハローワークで確かめてください。

## えんまーるとの使い分け

<!-- 【要確認】表現は特定募集情報等提供事業の範囲で。代表・原崎の確認を受ける -->

保いっぷは、就職先を一緒に探してくれる県の窓口です。えんまーるは、午前のみ・単発・週1などの短い時間の募集を自分で見て応募できる情報提供プラットフォームです。「まずは短い時間で現場の感覚を取り戻したい」という方は、えんまーるの募集もあわせて見てみてください。

| | 保いっぷ | えんまーる |
|---|---|---|
| どんなところか | 長崎県の就職支援の窓口 | 園の募集情報を掲載する情報提供プラットフォーム |
| 進め方 | スタッフに希望を伝え、見学や面接の日程を調整してもらう | 募集を自分で見て、自分で応募する |
| 向いている人 | 相談しながら、続けて働く園を探したい人 | 午前のみ・単発・週1など、短い時間から試したい人 |

どちらか一方に決める必要はありません。雇用契約は、どちらの場合も園と直接結びます。
